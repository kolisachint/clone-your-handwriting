# scans/

This folder holds the photos or scans of your filled-in handwriting sheets.
The font is built from the files in here.

## What to put here

- One image per template page.
- Name them `page-1.jpg`, `page-2.jpg`. The numbers keep them in order.
- Any common image type works: JPG, PNG, TIFF, WEBP, BMP.
- iPhone: use JPG, not HEIC. Go to Settings, Camera, Formats,
  then choose "Most Compatible".

## Photo tips

- Scanner at 300 dpi is best.
- A phone photo is fine if:
  - the page is flat on a table,
  - it is in daylight, with no shadow across the page,
  - all four black corner squares are inside the photo.
- Keep the whole page in frame. Crop only the outer margin.

## Adding them

Put the files here, then commit and push. Or run the build on your own
computer. See the main README.md.
